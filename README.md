# Разбор партии

Разбор шахматных партий в браузере: Stockfish (WASM), метки ходов (Brilliant … Blunder), точность,
график оценки, дебютная книга, пояснения, «Лучший ход / Объяснить / Повторить» и озвучка.
Партию можно загрузить по ссылке/id chess.com (публичный API) или вставить PGN.

## Запуск

```bash
npm install
npm run dev        # нейроголос работает только здесь (нужен .venv с edge-tts)
npm run build      # статическая сборка в dist/
```

Нейроголос: `python3 -m venv .venv && .venv/bin/pip install edge-tts`. На статическом хостинге
(GitHub Pages) используются системные голоса браузера.

## Лицензии и данные

- Stockfish — GPLv3, поэтому проект распространяется под GPL-3.0-or-later.
- Фигуры cburnett и chessground — из проекта Lichess (GPL).
- Дебютная база — lichess-org/chess-openings (CC0).
- Метки ходов основаны на публичном описании модели ожидаемых очков chess.com; это независимая
  реализация, не связанная с chess.com.
